02 / IOT SYSTEM

Home Security
System.

Project Overview

Sistem keamanan rumah berbasis Nuvoton NUC140 dengan dua titik sensor infrared dan photodiode untuk mendeteksi potensi intrusi.

Objectives

Mendeteksi gangguan pada jalur pengawasan dan memberikan peringatan secara cepat melalui indikator visual dan suara.

Features

Dual sensor detection, LED indicator, buzzer alarm, dan pemrosesan kondisi keamanan menggunakan Nuvoton NUC140.

Technologies

Keil MDK

Hardware Components

Nuvoton NUC140 Modul Infrared LED Buzzer Resistor

Project Gallery

RESULTS

  • Berhasil mendeteksi pergerakan objek melalui dua sensor infrared.
  • Memberikan peringatan visual dan suara berdasarkan kondisi gangguan.
  • Sistem menunjukkan kinerja yang responsif dan andal menggunakan mikrokontroler Nuvoton NUC140.
