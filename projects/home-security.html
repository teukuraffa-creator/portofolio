02 / IOT SYSTEM

Home Security
System.

Project Overview

A Nuvoton NUC140-based home security system using two infrared sensor points and photodiodes to detect potential intrusions.

Objectives

Detects disruptions along the monitoring path and provides rapid alerts through visual and audible indicators.

Features

Features dual-sensor detection, LED indicators, a buzzer alarm, and security condition processing using the Nuvoton NUC140 microcontroller.

Technologies

Keil MDK

Hardware Components

Nuvoton NUC140 Modul Infrared LED Buzzer Resistor

Project Gallery

RESULTS

  • Successfully detects object movement using two infrared sensors.
  • Provides visual and audible alerts based on detected disturbances.
  • The system demonstrates responsive and reliable performance using the Nuvoton NUC140 microcontroller.
